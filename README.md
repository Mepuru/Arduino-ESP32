## 项目列表

### [🔵 st7789_demo](st7789_demo/) — ST7789 显示屏驱动

ESP32-S3 + ST7789 240×240 SPI TFT LCD 的 Arduino 示例。

| | |
|---|---|
| **核心** | TFT_eSPI 库驱动 |
| **接线** | CS=10, DC=5, RST=6, MOSI=11, SCLK=12, BL=21 |
| **要点** | ESP32-S3 需 `USE_HSPI_PORT` 避免崩溃 |
| **演示** | 纯色切换、图形、文字、系统信息、弹球动画 |
